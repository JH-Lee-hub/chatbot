연결
이 기기에만 저장되며, 데이터 내보내기 파일에도 포함되지 않습니다.
캐릭터별로 다른 모델을 지정할 수도 있습니다.
기본 모델이 429나 장애로 실패하면 위에서부터 순서대로 자동 재시도합니다. 무료 모델은 거부가 잦으므로 최소 하나는 지정하시는 편이 좋습니다.
생성 파라미터
대화 원문은 전부 보존됩니다. 이 값은 매 요청에 실어 보낼 분량의 상한입니다. 대화가 길어져도 이 선에서 고정되므로 비용과 속도가 일정하게 유지됩니다. 긴 서술 포맷에서는 인물 카드만 2천 토큰을 넘깁니다. 대화가 어긋난다면 이 값을 올리십시오. 무료 모델 기준 12000까지는 부담이 없습니다.
단기 창 밖으로 밀려난 대화가 6턴 쌓이면 요약해 장기 기억에 병합합니다. 별도 API 호출이 발생하며, 전체 호출량의 약 5%입니다. 끄면 오래된 맥락이 유실됩니다.
공통 규칙
출력 포맷, 분량, 시점, 인물의 자율성을 정합니다. 각 대상의 추가 지침이 이 뒤에 덧붙으므로, 여기에는 인물과 무관한 공통 사항만 두십시오.
이미지 생성
OpenRouter의 이미지 모델은 전부 안전필터가 걸려 있어 따로 씁니다. Venice는 선불 크레딧 방식이고 구독이 필요 없습니다.
대화에서 이미지 생성 요청 이라고 보내면 비용을 먼저 묻습니다. 생성된 그림은 대화와 함께 기기에 저장되므로 백업 파일이 커집니다.
데이터
브라우저 데이터를 지우면 대화가 사라집니다. 자동 백업 구현 전까지 주 1회 내보내기를 권장합니다. 대화 하나만 따로 빼려면 대화 목록의 ⋯ 또는 채팅 화면의 ⋯에서 내보내십시오.
