생성 파라미터
매 요청 끝에서 다시 한번 지시하는 목표 분량입니다. 대화가 길어지면 모델이 앞선 응답의 길이를 따라 계속 늘리는 성질이 있어, 공통 규칙만으로는 제어되지 않습니다. 최대 출력은 이 값의 1.5배 안팎으로 두십시오. 너무 낮으면 문장이 잘립니다.
한 장면에 오래 머물면 모델이 같은 문형을 수백 번 되풀이하거나 외국어 낱말을 섞기 시작합니다. 이 값을 올리면 이미 쓴 표현에 벌점을 매겨 그런 무너짐을 억제합니다. 0.3 을 권합니다. 0.6 을 넘기면 문장이 부자연스러워집니다.
대화 원문은 전부 보존됩니다. 이 값은 매 요청에 실어 보낼 분량의 상한입니다. 대화가 길어져도 이 선에서 고정되므로 비용과 속도가 일정하게 유지됩니다. 긴 서술 포맷에서는 인물 카드만 2천 토큰을 넘깁니다. 대화가 어긋난다면 이 값을 올리십시오. 무료 모델 기준 12000까지는 부담이 없습니다.
Nemotron · GLM 같은 추론 모델은 사고 과정을 본문에 섞어 내보내는 일이 있습니다. 영어로 된 집필 계획만 나오고 장면이 안 써지면 이 항목을 켜 두십시오. 출력 토큰도 아낍니다.
단기 창 밖으로 밀려난 대화가 6턴 쌓이면 요약해 장기 기억에 병합합니다. 별도 API 호출이 발생하며, 전체 호출량의 약 5%입니다. 끄면 오래된 맥락이 유실됩니다.
공통 규칙
출력 포맷, 분량, 시점, 인물의 자율성을 정합니다. 각 대상의 추가 지침이 이 뒤에 덧붙으므로, 여기에는 인물과 무관한 공통 사항만 두십시오.

대상 탭의 🎲 → 선호형으로 만들 때만 쓰입니다. 완전 랜덤은 이 범위를 무시합니다. 평소 대화에는 실려 나가지 않으므로 토큰이 들지 않습니다.
이미지 생성
OpenRouter의 이미지 모델은 전부 안전필터가 걸려 있어 따로 씁니다. Venice는 선불 크레딧 방식이고 구독이 필요 없습니다.
노출이 없는 장면의 기본값입니다. 싸고 빠른 쪽을 고르십시오.
일반 장면에서 기본 모델이 실패했을 때, 또는 이미지 아이콘을 길게 눌러 고급을 고를 때 씁니다. 비싸지만 구도와 프롬프트 이해도가 낫습니다.
노출이 있는 장면은 수위와 무관하게 이 모델로 갑니다. Flux 같은 고급 모델은 성인향을 거부하거나 뭉개므로 여기에 지정하지 마십시오.
무검열 계열에는 더 비싼 상위 모델이 없습니다. 대신 스텝을 40으로 올리고 2배 업스케일을 걸어 품질을 끌어올립니다. 합계 약 $0.03으로 일반 고급과 같습니다.
장면을 영어 태그로 옮기는 데 씁니다. OpenRouter의 무료 모델은 수위가 있는 장면에서 작업을 거부하고, 그 거부 문장이 그대로 그림 프롬프트가 되어 엉뚱한 이미지가 나옵니다. Venice의 무검열 텍스트 모델을 쓰면 이 문제가 없습니다. 장당 $0.001 미만입니다.
길수록 장면을 촘촘히 옮기지만, SDXL 계열은 77토큰 단위로 끊어 읽어 뒤쪽 태그일수록 영향력이 줄어듭니다. 그래서 인물과 자세를 앞에, 배경과 질감을 뒤에 두도록 순서를 지시합니다. 매우 상세가 항상 더 좋은 그림을 주지는 않으니, 결과를 보고 상세와 비교해 보십시오. 태그 작성 호출 비용은 $0.001 미만입니다.
대화에서 이미지 생성 요청 이라고 보내면 비용을 먼저 묻습니다. 생성된 그림은 대화와 함께 기기에 저장되므로 백업 파일이 커집니다.
